## 📖 How to Customize

### 1. Edit Your Information

Open `index.html` in a text editor and replace:

```html
[Groom Name]      → Your groom's name
[Bride Name]      → Your bride's name
[Date: Day, Month Year]    → Wedding date (e.g., "Saturday, June 15, 2025")
[Time: HH:MM]     → Time (e.g., "6:00 PM")
[Venue Name], [City]       → Location
[email@example.com]        → Your email
[+216XXXXXXXX]   → Your phone number
```

### 2. Change Colors (Optional)

At the top of `index.html`, find the CSS variables:

```css
--primary-color: #8b4f6f;      /* Main color (purple) */
--secondary-color: #d4a574;    /* Accent color (gold) */
--accent-light: #f5f1e8;       /* Background color */
```

Replace with your preferred colors (hex codes).

### 3. Add Your Details

- Edit the Arabic welcome message if needed
- Update RSVP contact information
- Customize the footer message
